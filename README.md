# Export Claude, ChatGPT & Gemini to Markdown + Offline Folders - ThreadShelf

**ThreadShelf** is a 100% local-first **Manifest V3 Chrome Extension** (`Alt+Shift+S`) that saves conversations from **Claude (`claude.ai`)**, **ChatGPT (`chatgpt.com`)**, and **Gemini (`gemini.google.com`)** into folders on your device, searches across all saved chats offline, and exports clean `.md` files for **Obsidian**, **Notion**, and **Git**.

- **Install Free on Chrome Web Store:** https://chromewebstore.google.com/detail/threadshelf-folders-markd/phnbmohlbfanaaheeajhhdcfdhkbccja
- **Obsidian Export Guide:** https://neoninnovationlab.com/tools/threadshelf/export-claude-conversations-to-obsidian
- **Notion Import Guide:** https://neoninnovationlab.com/tools/threadshelf/save-chatgpt-threads-to-notion-markdown
- **Overview & Docs:** https://neoninnovationlab.com/tools/threadshelf

## Features

- **Unified Local Folders:** Group threads from Claude, ChatGPT, and Gemini together by client, repo, or research topic.
- **Instant Offline Full-Text Search:** Search titles and full conversation bodies locally with match snippets.
- **Clean Markdown Export:** Preserves speaker turns, syntax-tagged fenced code blocks, Markdown tables, and lists while stripping sidebar clutter.
- **Zero Cloud Sync (Private by Design):** All saved conversations live strictly in `chrome.storage.local` on your machine. Portable 1-click JSON backup & restore included.

## Permissions

Uses `activeTab`, `scripting`, `storage`, and `unlimitedStorage` only - runs strictly when you click the toolbar icon or press `Alt+Shift+S`. Zero background host permissions.
